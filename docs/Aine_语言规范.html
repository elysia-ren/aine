第一部分 · 入门教程1 你好,Aine

Aine 是一门静态类型的值语义语言:语法接近你所熟悉的现代语言,但一切赋值都是副本、一切变更都产生新值,没有悬垂指针、没有数据竞争、没有手动内存管理。源码先编译为 C,再编译为原生可执行文件。

1.1 第一个程序

新建文本文件 hello.aine:

fn main() {
    print("你好,Aine")
}

运行它:

aine run hello.aine
你好,Aine

编译为独立的原生可执行文件(不依赖任何运行时安装):

aine build hello.aine
hello.exe          ← 直接双击/执行

1.2 一眼看懂语法骨架

  • 函数用 fn 定义,程序从 main 开始;
  • print(…) 是内建打印,多个值用空格分隔;
  • 语句以换行结束,不需要分号;
  • 块用花括号,块尾的值就是这个块的值。
fn main() {
    let name = "Aine"
    print("你好," + name)          // 字符串用 + 拼接
    print(f"1+1={1 + 1}")           // f-string 插值
}
你好,Aine
1+1=2
f-string 里直接写表达式:f"结果: {a + b}",数值会自动格式化,不需要手动转换。

第一部分 · 入门教程2 变量与类型

2.1 let 与 var

let 声明不可变绑定,var 声明可变绑定。类型通常自动推断,也可以显式标注:

let x = 10               // 推断为 i32,不可变
var y = 20               // 可变
y = y + 5
let big: i64 = 123456789012   // 显式标注类型
let ratio: f64 = 0.5
重新赋值只能针对 var 绑定:x = 99 在上面的例子里是类型错误(T3010)。

2.2 基本类型

类型例子说明
i32 / i64-42 / 123456789012有符号整数;所有整数运算在 64 位域进行,声明宽度在显式转换与 FFI 边界生效
u8–u64 / usizelet b: u8 = 7无符号整数(同一 64 位算术域)
f64 / f322.5浮点(字面量默认 f64)
booltrue / false打印为 true / false
String"文本"拥有语义的 UTF-8 字符串,按字符索引(见第 7 章)
chars[0] 的结果恰好一个字符的 String(与单字符 String 可互赋)
数值字面量会适配标注类型:let i: i64 = 123456789012 合法。不同整数类型之间不隐式转换,需要 to_i32() / to_f64() 等显式方法。

2.3 一切赋值都是副本

let a = [1, 2, 3]
let b = a              // b 是独立副本
b = b.push(4)          // push 追加元素,返回新 Vec
print(a.len())          // 3 —— a 不受影响
print(b.len())          // 4
这就是 Aine 的安全地基:没有别名、没有悬垂引用、没有数据竞争。代价是显式的克隆成本——编译器的优化体系(设计冻结中)负责把它降下来。

第一部分 · 入门教程3 控制流

3.1 if / else 是表达式

let n = 7
if n > 3 {
    print("大")
} else {
    print("小")
}

// if 是表达式:两个分支的块尾值就是它的值
let level = if n > 5 { "高" } else { "低" }
print(level)            // 高

3.2 while 与 for-in

var i = 0
while i < 3 {
    print(i)
    i = i + 1
}

for i in 0..3 {        // 区间 0,1,2(不含 3)
    print(i)
}

for ch in "中文" {      // 字符串按字符迭代
    print(ch)            // 中 / 文
}
for-in 对 Vec<T> 逐元素、对 String 逐字符、对区间逐整数。循环变量在每次迭代产生,循环体内对它的修改不影响下一轮。

3.3 break 与 continue

for i in 0..10 {
    if i == 3 {
        continue          // 跳过本轮
    }
    if i > 5 {
        break             // 退出循环
    }
    print(i)              // 0 1 2 4 5
}

3.4 match:模式匹配

enum Shape {
    Circle(f64)
    Rect(f64, f64)
}

fn area(s: Shape) -> f64 {
    match s {
        Circle(r) => 3.14 * r * r
        Rect(w, h) => w * h
    }
}

match 也匹配 Option 与字面量:

match m.get("k") {
    Some(v) => print(v)
    None => print("没有")
}
match 各臂类型必须一致;`_` 是兜底臂。枚举变体的载荷按位置绑定到臂参数。

第一部分 · 入门教程4 函数

4.1 定义与调用

fn add(a: i32, b: i32) -> i32 {
    return a + b          // 也可以直接写 a + b(块尾值)
}

fn greet(name: String) {
    print(f"你好,{name}")
}

4.2 递归

fn fib(n: i32) -> i32 {
    if n < 2 {
        return n
    }
    return fib(n - 1) + fib(n - 2)
}

4.3 参数模式(进阶)

写法语义
fn show(u: User)按值传入(独立副本)——普通代码只用这个
fn store(move u: User)声明"我接管这个值"(第一版为文档性标注)
fn inspect(u: &User)高级借用视图(低频;禁返回、禁存储)

4.4 函数类型(统一,无 trait 三分法)

fn apply(f: fn(i32, i32) -> i32) -> i32 {
    return f(3, 4)
}

fn main() {
    print(apply(add))       // 7 —— 具名函数直接传
}

第一部分 · 入门教程5 集合:Vec 与 Map

5.1 Vec<T> 动态数组

var v = [1, 2, 3]          // 推断 Vec<i32>
v = v.push(4)              // 追加(产生新版本,须接住)
print(v.len())              // 4
print(v[0])                 // 1 —— 下标访问
v[0] = 10                  // 索引赋值

print(v.contains(2))       // true
v = v.remove(0)            // 删除下标 0
for x in v {               // 逐元素迭代
    print(x)
}
方法说明
push(x) / pop()追加 / 弹出尾部
insert(i, x) / remove(i)插入 / 删除指定位置
set(i, x) / get(i)替换 / 读取(越界 panic / None)
concat(other)拼接为新 Vec
len() / contains(x) / sort() / clear()长度 / 包含 / 排序 / 清空
Aine 的变更方法返回新值。语句形态 v.push(4)(不接住返回值)在解释器里会写回变量,但推荐始终写 v = v.push(4)——这是 C 后端与未来并发语义下的确定写法。

5.2 Map<K, V> 有序映射

var m: Map<String, i32> = Map.new()
m.set("苹果", 3)
m.set("香蕉", 5)

print(m.get("苹果"))       // Some(3)
print(m.get("梨"))         // None
print(m.contains("香蕉"))  // true
print(m.len())              // 2

for k in m.keys() {        // 键迭代(插入序)
    print(k)
}
for v in m.values() {      // 值迭代
    print(v)
}

5.3 嵌套容器

var grid: Vec<Vec<i32>> = []
var stock: Map<String, Vec<i32>> = Map.new()

第一部分 · 入门教程6 结构体与枚举

6.1 struct:命名字段

struct User {
    name: String
    age: i32
}

fn main() {
    var u = User { name: "张三", age: 25 }
    print(u.name)          // 张三
    u.age = u.age + 1      // 字段赋值(需 var)
    print(u.age)           // 26
}

6.2 enum:带载荷的变体

enum Event {
    Click(String)
    Move(i32, i32)
    Quit
}

fn handle(e: Event) {
    match e {
        Click(target) => print(f"点击 {target}")
        Move(x, y) => print(f"移动 {x},{y}")
        Quit => print("退出")
    }
}
枚举变体的载荷按位置绑定到臂参数。match 必须覆盖所有变体(或以 `_` 兜底)。

第一部分 · 入门教程7 字符串

7.1 码点模型

Aine 字符串按 Unicode 码点计量:len() 是字符数、s[i] 是第 i 个字符、切片按字符位。你永远不需要关心 UTF-8 字节。

let s = "中a文b"
print(s.len())          // 4(不是 8 个字节)
print(s[0])             // 中
print(s[1..3])          // a文
print(s[0] == "中")     // true

7.2 常用方法

方法例子结果
trim()" hi ".trim()"hi"(含全角空格)
split(sep)"a,b".split(",")Vec<String>
contains(s)"hello".contains("ell")true
starts_with(s) / ends_with(s)"ab".starts_with("a")true
replace(a, b)"aa".replace("a", "b")"bb"
to_i32() / to_f64()"42".to_i32()42

7.3 拼接与格式化

let name = "Aine"
let version = 1.5
print(f"{name} v{version}")          // Aine v1.5
print(f"{name.len()} 个字符")        // 4 个字符
f-string 对任意表达式求值:数值、bool 自动格式化;字符串原样嵌入。拼接也可以用 +(两侧同为字符串)。

第一部分 · 入门教程8 错误处理

8.1 Option:有或没有

let m: Map<String, i32> = Map.new()
let hit = m.get("k")       // Option<i32>
match hit {
    Some(v) => print(v)
    None => print("没有")
}
print(hit)                  // 直接打印: Some(…) / None

8.2 Result 与 ?

fn load(path: String) -> Result<String, String> {
    let text = read_file(path)
    if text.contains("[read_file error") {
        return Err("读取失败")
    }
    return Ok(text)
}

fn main() {
    let text = load("a.txt")?   // 失败则 main 返回 Err
    print(text)
}
`?` 要求操作数类型与所在函数的错误通道一致(Option 函数内用 Result 的 `?` 是类型错误)。

8.3 defer:退出时必执行

fn work() {
    defer print("收尾")     // 所有退出路径都会执行,LIFO
    print("工作中")
}
// 输出: 工作中 → 收尾

8.4 panic:程序缺陷,不可捕获

以下情形产生确定性 panic(终止程序,消息含函数栈):索引越界、Map 键不存在、assert 失败、类型不匹配、栈超限、defer 内出错、除零。业务失败永远用 Result,不用 panic。

第一部分 · 入门教程9 闭包与 defer

9.1 闭包

let base = 10
let add_base = |x| x + base     // 捕获 base 的快照
print(add_base(5))               // 15

let add = |a: i32, b: i32| a + b // 独立闭包(参数带类型)
print(add(1, 2))                 // 3
捕获发生在创建时(快照语义):之后修改外部变量不影响已创建的闭包。闭包与具名函数是同一类型 fn(A) -> R,可以互相传递。

第一部分 · 入门教程10 模块与多文件

用 module 把源码按文件组织,入口文件声明后即可使用其中的一切:

// —— 文件 stdlib/json.aine ——
fn stringify(j: Json) -> String { … }

// —— 文件 main.aine ——
module json;

fn main() {
    print(json.stringify(value))
}

标准库(stdlib/)提供 json 等模块,按搜索路径自动解析。

第三部分 · 语义规范16 值语义与内存模型

16.1 三层模型(冻结)

语义拥有优先,编译器借用优化,显式借用高级化。

用户层只面对拥有值;编译器内部(View/Owned/Materialized)自由选择且不可观察;高级层(&/move/unsafe)显式才存在。例外入口仅三处:move(文档性标注)、@global(并发可达)、extern 边界。

16.2 变更语义

  • 一切赋值与传参 = 独立副本;
  • 容器变更方法产生新版本(旧持有者观察不变),C 实现为 clone-then-mutate;
  • push/insert/remove 写回接收者变量(与解释器一致);
  • 自引用初始化 var x = x + 1 读外层 x(C 侧经临时捕获保证)。

16.3 整数算术域(SD-1)

+ - * / % 在 64 位有符号域执行;声明宽度在显式窄化(to_i32 等/FFI)时按二补数环绕生效;extern 签名保持 C ABI。不变量:宿主与 C 后端整数结果逐位一致。

16.4 Materialization 与优化 只有意图

视图化(D1 四条件)/物化三档诊断(64KB/1MB)/禁隐式大型 Clone(§10 禁"静默"复制)——实现未启动;"零额外分配"是优化目标,不是语言保证(M-6)。

第三部分 · 语义规范17 错误语义与 panic 词表

17.1 panic 构造词表(封闭)

以下产生 panic(终止程序,消息含函数栈),不可被普通 catch(D9):

  1. 索引/切片越界;2. Map 键不存在;3. assert 失败;4. 运行时类型不匹配;5. 调用栈超限(500);6. defer 体内出错(abort);7. 整数除零。

17.2 defer 全退出路径(D13/SD-2)

正常返回、early return、panic 冒泡、`?` 传播、可捕获异常——全部 LIFO 执行;defer 体内再出错 = abort(立即以该错误终止)。

17.3 try/catch 边界(D9)

仅 FFI exception、平台 exception、#[catchable] 函数可捕获;普通 panic 的 catch 为编译期拒绝;`#[catchable]` 仅限 unsafe/FFI 模块。已定义(宿主 TryCatch 实现;C 路径 AST 缺失,登记 W6)

规则按职能五分类:定义(saṃjñā)/操作(vṛtti)/例外(niyama)/管辖(adhikāra)/元规则(paribhāṣā)。每条规则的含义来自它与体系中其他规则的关系——因此本规范每条规则都标注编号与管辖域。
