第一部分 · 零基础入门0 开始之前:你需要准备什么

这一部分假设你从来没有写过程序。每一章只教一个概念,每个例子都可以亲手运行,并告诉你屏幕上会出现什么。

0.1 什么是程序

程序就是写给计算机的菜谱:一步一步告诉计算机先做什么、再做什么、遇到什么情况怎么办。你把菜谱写在一个文本文件里(后缀是 .aine),然后让 Aine 的工具照着执行。

菜谱上写"打三个鸡蛋、加一勺盐、翻炒"——计算机也一样,你说一步它做一步,顺序不能乱、步骤必须写清楚。

0.2 你需要准备的东西

东西是什么从哪来
aine.exeAine 的工具,负责"照菜谱执行"和"把菜谱翻译成独立程序"项目仓库 flowc/target/release/aine.exe(或找 aiden 要编译好的)
一个文本编辑器写菜谱用的纸。记事本就够用;VS Code 更舒服系统自带或免费下载
一个文件夹放你的菜谱和工具自己建一个,比如 D:\aine-start

把 aine.exe 复制到你的文件夹里。下面所有章节都假设:你的菜谱和 aine.exe 在同一个文件夹。

0.3 终端:你和计算机对话的窗口

"终端"就是一个输入文字命令的窗口。打开方式(Windows):在文件夹的地址栏输入 cmd 然后回车;或按 Win 键输入"命令提示符"再 cd 到你的文件夹。

cd /d D:\aine-start

接下来所有章节里,凡是"在终端里输入"的命令,都是在这个窗口里敲、然后按回车。

打开终端,输入 aine.exe --help 并回车。看到一大段使用说明(而不是"不是内部或外部命令")就说明工具就位了。

第一部分 · 零基础入门1 第一个程序:让计算机说话

1.1 写下菜谱

用记事本在你的文件夹里新建文件 hello.aine,输入下面两行,保存:

fn main() {
    print("你好,Aine")
}

逐行解释:

  • fn main() { —— 每个程序都从叫 main 的地方开始执行;花括号 { 表示"从这里开始";
  • print("你好,Aine") —— 让计算机把括号里的文字显示到屏幕上;print 意思是"打印";
  • } —— main 到这里结束。
文字要用双引号包起来,就像信封装信——告诉计算机"这是一段要原样使用的文字",而不是别的指令。

1.2 运行它

在终端里输入:

aine.exe run hello.aine

屏幕上会显示:

你好,Aine

恭喜——你已经运行了第一个程序。改改引号里的文字,保存,再运行一次,看输出怎么变。

常见错误:引号忘了写后半边;花括号只有 { 没有 };把 print 拼错。出错时工具会告诉你第几行出了什么问题——第 10 章专门教你怎么读错误消息。
写一个程序,让屏幕上出现你朋友的名字和一句话。

第一部分 · 零基础入门2 变量:给东西贴上名字

2.1 变量是一个贴了标签的盒子

变量就是一个盒子,盒子上贴着你起的名字,盒子里放着一样东西(一个数、一段文字……)。以后要用这样东西,喊盒子的名字就行。
fn main() {
    let name = "小明"
    let age = 12
    print(name)
    print(age)
}
小明
12

let name = "小明" 读作:"做一个叫 name 的盒子,里面放文字 小明。"

2.2 let 和 var:能不能换盒子里的东西

let 贴的是封条:东西放进去就不能换。var 没有 封条:随时可以放新东西进去(这叫"重新赋值"):

var score = 60
print(score)          // 60
score = 95
print(score)          // 95

score = 95 读作:"把 score 盒子里的东西换成 95"。只写 let 的盒子换东西会报错——这是语言故意保护你:不该变的东西被不小心改掉,是很多错误的来源。

2.3 盒子里能放哪几种东西(类型)

种类(类型)例子说明
整数(i32)12、-7、0没有小数点的数
小数(f64)2.5、-0.5带小数点的数
文字(String)"小明"用引号包起来的字符,叫字符串
真假(bool)true / false只有两种:真、假

"类型"就是盒子里东西的种类。数字和文字不能混着算——"abc" + 3 这类操作会被拒绝。类型可以在名字后面用冒号写明:

let score: i32 = 100
let title: String = "成绩单"
做三个盒子:你的名字、你的年龄、今天是不是晴天(true/false)。然后把它们都打印出来。

第一部分 · 零基础入门3 数字与计算

3.1 四则运算

print(3 + 4)            // 7
print(10 - 2 * 3)       // 4 —— 先乘除后加减,和数学一样
print(7 / 2)            // 3 —— 整数除(见 SD-1 注)
print(7 % 2)            // 1 —— % 是"除完剩下的余数"

3.2 把计算结果放进话里(f-string)

在引号前加一个 f,花括号里的计算会被替换成结果:

let a = 3
let b = 4
print(f"直角边 {a} 和 {b},斜边平方是 {a * a + b * b}")
直角边 3 和 4,斜边平方是 25

3.3 大数与小数

let big: i64 = 123456789012     // 很大的整数,标注 i64
let price = 9.9                 // 小数
print(price * 3)                // 29.7
所有整数计算都在 64 位域进行,不会突然溢出;需要精确的 32 位边界时用 to_i32() 显式收窄。
算一下:一年 365 天,你活了 30 年,大约多少天?打印出来。

第一部分 · 零基础入门4 文字:字符串

4.1 字符串就是一串字符

let s = "hello"
print(s.len())            // 5 —— 字符个数(中文按字数,不是按字节)
print(s[0])               // h —— 第 0 个字符(从 0 开始数!)
从 0 开始数:第 1 个字符的位置是 0,第 2 个是 1……几乎所有编程语言都这样,记住它。

4.2 常用操作

print(s + " world")        // hello world —— 拼接
print(s.contains("ell"))   // true —— 包含吗
print(s.trim())            // 去掉两头的空格
print("a,b,c".split(",").len())   // 3 —— 按逗号切成三段

4.3 中文字符

中文按字数,不按字节:

let s = "中文"
print(s.len())            // 2 —— 两个字符
print(s[0] == "中")       // true
把你的名字存进变量,打印它的字符数和第一个字符。

第一部分 · 零基础入门5 做决定:如果……就……

5.1 if 和 else

下雨就带伞,否则戴帽子——程序里的"做决定"就是这个结构:如果条件成立,做甲;否则做乙。
let temp = 35
if temp > 30 {
    print("开空调")
} else {
    print("不用")
}
// 输出: 开空调

5.2 比较与真假

写法意思例子(结果)
==相等吗3 == 3(true)
!=不相等吗3 != 4(true)
> < >= <=大于/小于/不小于/不大于5 >= 5(true)

比较的结果是一种叫 bool 的东西,只有两个值:true(真)和 false(假)。可以用 &&(并且)、||(或者)、!(取反)组合:

let age = 20
let has_ticket = true
if age >= 18 && has_ticket {
    print("可以入场")
}

5.3 else if:多路决定

let score = 85
if score >= 90 {
    print("优")
} else if score >= 80 {
    print("良")
} else {
    print("继续努力")
}
// 输出: 良
写程序:一个变量存温度,超过 35 打印"高温预警",30 到 35 打印"偏热",否则打印"舒适"。

第一部分 · 零基础入门6 重复:让计算机干活

6.1 for:数着来

"从 1 数到 100"——计算机最擅长的就是不知疲倦地重复。
for i in 0..5 {
    print(i)
}
// 0 1 2 3 4 —— 从 0 开始,到 5 之前停(不含 5)

6.2 while:满足条件就一直做

var cups = 3
while cups > 0 {
    print(f"还剩 {cups} 杯")
    cups = cups - 1       // 别忘了让条件最终不成立,否则永远停不下来!
}

6.3 对集合逐个处理

let names = ["张三", "李四", "王五"]
for name in names {
    print(name)           // 张三 → 李四 → 王五
}

for ch in "中文" {        // 字符串也能逐字符
    print(ch)
}

6.4 break 与 continue

for i in 0..10 {
    if i == 3 { continue }   // 跳过 3
    if i > 5 { break }       // 到 6 就停
    print(i)                  // 0 1 2 4 5
}
用循环打印 1 到 100 里所有 7 的倍数。

第一部分 · 零基础入门7 列表与名册:Vec 和 Map

7.1 Vec:一排盒子

Vec 就是一排编了号的盒子:第 0 格、第 1 格、第 2 格……编号从 0 开始。
var fruits = ["苹果", "香蕉"]
fruits = fruits.push("橘子")     // 加一个到末尾
print(fruits.len())               // 3 —— 有几格
print(fruits[0])                  // 苹果 —— 第 0 格
fruits[0] = "梨"                  // 把第 0 格换成梨
print(fruits)                     // [梨, 香蕉, 橘子]
做法效果
v.push(x)末尾加一个
v.insert(i, x)插到第 i 格
v.remove(i)删掉第 i 格
v.set(i, x)把第 i 格换成 x
v.get(i) / v[i]读第 i 格
v.len() / v.contains(x)几格 / 有没有
v.concat(w)把 w 接到后面,得到新列表

7.2 Map:按名字找的柜子

Map 像储物柜:不记编号,记标签。"apple" 那格放 3,"banana" 那格放 5——按标签取,不用背编号。
var stock: Map<String, i32> = Map.new()
stock.set("apple", 3)
stock.set("banana", 5)

print(stock.get("apple"))       // Some(3) —— 找到了
print(stock.get("pear"))        // None —— 没有这一格
stock.set("apple", 10)           // 同名格子:内容被替换
print(stock.len())               // 2
get 的结果包在 Some(…) 里——这是语言在提醒你"这一格可能不存在"。用 match 处理(见第 10 章)。
建一个你最近三天睡觉小时数的 Vec,打印每天的和总平均。

第一部分 · 零基础入门8 函数:把做法做成菜谱

8.1 为什么要函数

"番茄炒蛋"的做法一旦写好,每次想吃就直接念菜谱名,不用每次重新描述。函数就是给一段常用做法起名字。
fn greet(name) {
    print(f"你好,{name}!")
}

fn main() {
    greet("张三")      // 你好,张三!
    greet("李四")      // 你好,李四!
}

name 是参数——菜谱的配料:调用时给它什么,函数里就用什么。

8.2 返回值:菜谱的成品

fn add(a, b) {
    return a + b         // return = 把这个结果交还给调用的人
}

print(add(2, 3))         // 5
print(add(2, 3) * 10)    // 50 —— 返回值能继续参与计算

8.3 带类型标注(进阶)

fn add(a: i32, b: i32) -> i32 {
    return a + b          // 冒号后是配料种类; -> 后是成品种类
}
类型标注不是必须的(Aine 会推断),但写出来能获得更早的错误检查——建议养成习惯。

8.4 递归:函数调用自己(进阶)

fn count_down(n) {
    if n == 0 {
        print("发射!")
        return
    }
    print(n)
    count_down(n - 1)     // 自己调用自己,每次少 1
}
// count_down(3) → 3 2 1 发射!
写函数 square(x) 返回 x 的平方;再用它打印 1 到 5 的平方。

第一部分 · 零基础入门9 自己的类型:struct 与 enum

9.1 struct:一张登记表

学生登记表:姓名、年龄、班级——几个格子固定,每张表填一份。
struct Student {
    name: String
    age: i32
}

fn main() {
    var s = Student { name: "张三", age: 12 }
    print(s.name)          // 张三
    s.age = 13             // 过生日了,改一格
    print(s.age)           // 13
}

9.2 enum:有限个选项

交通灯只有红、黄、绿三种状态——枚举就是"把所有可能的种类列出来,别的都不允许"。
enum Light {
    Red
    Yellow
    Green
}

fn action(light: Light) {
    match light {
        Red => print("停")
        Yellow => print("等一等")
        Green => print("走")
    }
}

9.3 match:按种类分头处理

enum Shape {
    Circle(f64)              // 变体可以带" payload "(附加信息)
    Rect(f64, f64)
}

fn area(s: Shape) -> f64 {
    match s {
        Circle(r) => 3.14 * r * r        // 把载荷取名叫 r 来用
        Rect(w, h) => w * h
    }
}

print(area(Shape.Circle(2.0)))       // 12.56
match 还能匹配 Option(第 7 章的 Some/None)和字面量。`_` 是"其余全部"的兜底臂。
定义 enum Season(四季),写函数按季节打印一句建议。

第一部分 · 零基础入门10 出错了怎么办

10.1 错误消息是帮手,不是敌人

程序出错时,Aine 会告诉你:哪个文件、第几行、什么问题、怎么改。比如把 print 拼成 prnt:

error[N3001]: 未定义的名称 'prnt'
 --> hello.aine:2:5
  |
2 |     prnt("你好")
  |     ^^^^
  |
  = 建议: 未定义的名称 'prnt'。Aine 中使用的每个名字都需要先声明

读法:先看行号(2:5 = 第 2 行第 5 列),再看错误码(N3001 = 名字没定义),最后读建议。改完再运行,逐个消灭。

10.2 两类错误

类别什么时候发现例子
编译错误(N/T 开头)运行之前——程序根本没跑名字拼错、类型不匹配、少了括号
运行时错误(panic)跑到一半才炸取了列表里不存在的格子、除以零

10.3 运行时错误:你的程序有缺陷

let v = [1]
print(v[5])
运行时错误: 索引越界: idx=5 len=1 vec=[1] 于函数 main

消息把你要的编号、列表实际长度、列表内容、出错的函数都告诉你了——照着改就行。这类"程序缺陷"在 Aine 里不可被捕获(它会诚实地暴露 bug),列表可能为空的情形请用 get(返回 Option)。

故意制造一个越界错误,读懂消息,再把它修好。

第一部分 · 零基础入门11 进阶一瞥(知道有这些就够)

11.1 defer:收尾动作

fn work() {
    defer print("收尾")     // 离开函数时一定会执行(倒序)
    print("干活")
}

11.2 @global:全程序共用的格子

@global var visits = 0

fn hit() {
    visits = visits + 1
}

11.3 闭包:把一段做法存起来

let base = 10
let add_base = |x| x + base
print(add_base(5))       // 15

11.4 模块:把代码分到多个文件

module json;          // 引入 stdlib/json.aine 里的全部内容
这些特性在第二、三部分有完整参考。学到这里,你已经能写有实际用途的小程序了——去写吧,遇到问题查第二部分,想理解为什么查第三部分。

空白 = 空格/制表/回车/换行;换行是软语句终结符。注释:// 行注释;/* … */ 块注释(可嵌套)。

11.2 字面量

IntLiteral    ::= DecInt | '0x' HexDigit {…} | '0b' Bit {…} | '0o' Oct {…}
FloatLiteral  ::= Digit {…} '.' Digit {…} [Exponent] | Digit {…} Exponent
StrLiteral    ::= '"' { StrChar | Escape } '"'
FmtStrLiteral ::= 'f' '"' { StrChar | Escape } '"'
Escape        ::= '\' ('n' | 't' | 'r' | '0' | '\' | '"' | ''' | 'x' HexDigit HexDigit)

11.3 运算符

算术 + - * / %;比较 == != < <= > >=;逻辑 && || !;位 & | ^ ~ << >>;复合赋值 += -= *= /= %=;区间 ..;Try ?;解引用 * &(高级)。

Primary ::= IntLiteral | FloatLiteral | StrLiteral | FmtStrLiteral | 'true' | 'false'

第三部分 · 语义规范16 值语义与内存模型

16.1 三层模型(冻结)

语义拥有优先,编译器借用优化,显式借用高级化。

用户层只面对拥有值;编译器内部(View/Owned/Materialized)自由选择且不可观察;高级层(&/move/unsafe)显式才存在。例外入口仅三处:move(文档性标注)、@global(并发可达)、extern 边界。

16.2 变更语义

  • 一切赋值与传参 = 独立副本;
  • 容器变更方法产生新版本(旧持有者观察不变),C 实现为 clone-then-mutate;
  • push/insert/remove 写回接收者变量(与解释器一致);
  • 自引用初始化 var x = x + 1 读外层 x(C 侧经临时捕获保证)。

16.3 整数算术域(SD-1)

+ - * / % 在 64 位有符号域执行;声明宽度在显式窄化(to_i32 等/FFI)时按二补数环绕生效;extern 签名保持 C ABI。不变量:宿主与 C 后端整数结果逐位一致。

16.4 Materialization 与优化 只有意图

视图化(D1 四条件)/物化三档诊断(64KB/1MB)/禁隐式大型 Clone(§10 禁"静默"复制)——实现未启动;"零额外分配"是优化目标,不是语言保证(M-6)。

第三部分 · 语义规范17 错误语义与 panic 词表

17.1 panic 构造词表(封闭)

以下产生 panic(终止程序,消息含函数栈),不可被普通 catch(D9):

  1. 索引/切片越界;2. Map 键不存在;3. assert 失败;4. 运行时类型不匹配;5. 调用栈超限(500);6. defer 体内出错(abort);7. 整数除零。

17.2 defer 全退出路径(D13/SD-2)

正常返回、early return、panic 冒泡、`?` 传播、可捕获异常——全部 LIFO 执行;defer 体内再出错 = abort(立即以该错误终止)。

17.3 try/catch 边界(D9)

仅 FFI exception、平台 exception、#[catchable] 函数可捕获;普通 panic 的 catch 为编译期拒绝;`#[catchable]` 仅限 unsafe/FFI 模块。已定义(宿主 TryCatch 实现;C 路径 AST 缺失,登记 W6)
