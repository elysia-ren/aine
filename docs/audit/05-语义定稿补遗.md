## SD-1 整数算术域(P0-1 定稿,已实现)【类型:定义】

- **定稿**:Aine 整数算术(+ - * / %)一律在 **64 位有符号域**执行;`i32` 声明的存储宽度仅在**显式窄化**(`to_i32()`/FFI 边界)时生效,窄化按 C23 modular(二补数环绕)定义;`i32` 的 C 表示 = `long long`(extern ABI 例外:extern 函数签名保持 C `int`)。
- **理由**:§3.4 确定性优先(消除 C 有符号溢出 UB);§3.3(无运行时检查税);与参考实现(宿主 i64 值模型)零改动对齐(M-5);Lua/JS 先例(单一宽域 + 显式窄化)。
- **实现**:altype `c_type("i32")="long long"`;alee SLet-EInt/EVec 元素/EIndex/SFor/arg_elem_size/map-i 存取/`al_num(long long)`/print 全 `%d`→`al_num` 链;extern 走 `c_param_decl_ffi`(i32=int)。
- **验证**:ovf.aine 双路一致(`2147483647+1` = 2147483648);自测 31/31(断言已同步 64 位 ABI);cargo 180;awen-proto 词法验收 ✓。
- **余项**:宿主 `Value::Int` 仍为 i64 = 与定稿一致 ✓;u8-u64/usize 的算术域未定(后续 T1.0 增补)。

## SD-2 defer 全退出路径(P0-2 定稿,已实现)【类型:操作】

- **定稿**:defer 在正常返回/early return/panic 冒泡/`?` 传播**全部路径** LIFO 执行(D13 本义);**defer 体内再出错 = abort 语义**(立即以该错误终止,剩余 defer 跳过)。
- **实现**:宿主 `call_fn_inner` 统一在 result 之后执行 `run_defers`(Err 分支不再丢弃);conformance:df.aine(panic 路径)+ dfn.aine(LIFO)双路验证。
- 证据:interp.rs call_fn_inner;01 总表 D-5 更新。

## SD-3 `?` 的 Option/Result 交叉(P0/W10 定稿提案)【类型:定义】

- **定稿**:`e?` 要求 e 的类型与**所在函数的错误通道一致**——返回 `Result<T,E>` 的函数内 `opt?`(Option)= 类型错误(T3005);反之亦然。混合通道是设计错误,不做自动映射。
- **理由**:Lojban 式"句法合法 ≠ 语义正确"的显式分离;自动映射(Err(Option::None))制造幽灵错误值。
- **状态**:定稿;typeck 检查待实现(需要函数返回类型上下文穿透)。

## SD-4 char ≡ 1 字符 String(W13 定稿提案)【类型:定义】

- **定稿**:`char` 类型保留但定义为"恰好一个 Unicode 码点的 String"——与 D15 完全一致;`s[i]` 的结果类型即 char(=1 字符 String);两者可无条件互赋;C 表示统一 `char*`(al_char_at)。
- **理由**:消灭双类型互转规则(D15 单一计量单位的自然延伸);宿主/C 实测行为本已如此。
- **状态**:定稿;T1.0 §1.1 char 行待更新措辞。

## SD-5 panic 构造词表(W16 定稿提案)【类型:定义】

- **定稿**:以下运行时错误为 **panic 类**(不可被普通 catch,D9;全部 `abort` 语义):
  1. 索引/切片越界;2. Map 键不存在;3. `assert` 失败;4. 运行时类型不匹配(调用非闭包值等);5. 调用栈超限(500);6. defer 体内出错(SD-2);7. 整数除零。
- **理由**:D9"明确允许捕获的 panic"需要封闭清单才可执行;以上全部是**程序缺陷**而非业务失败(业务失败走 Result)。
- **状态**:定稿;与 D9 的 `#[catchable]`(FFI 边界)衔接。

## SD-6 move 第一版 = 文档性标注(W3/P1-2 定稿提案)【类型:定义】

- **定稿**:`move` 参数标记第一版**不产生可观察语义差异**(值语义下实参已是独立副本,所有权转移无可观察效果;失效检查无对象——调用方绑定不受影响)。`move` 保留为**意图标注**(文档/IDE 提示),真实的所有权转移语义随 Phase 2 所有权状态机(A-10)设计。
- **理由**:值语义下"转移后失效"需要调用侧语法与借用检查器,均为 Phase 2 范围;显式决定优于未决定的语法存在。
- **状态**:定稿(有意识决定 ✓);登记簿建议补记。

## SD-7 捕获语义 = 快照(W21/P3-7 定稿提案)【类型:定义 + 裁决记录】

- **定稿**:闭包捕获语义 = **创建时快照**(D14),§25 的"Borrow→Copy→Move 推导优先级"章节废止待修订(元规则 M-4 首例裁决:后定稿优先)。
- **状态**:定稿;§25 修订待设计评审;`move name` 显式快照触发语法随 W3/SD-6 一并定稿(同为文档性标注)。
