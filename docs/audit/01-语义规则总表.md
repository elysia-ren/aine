## A. 值语义与内存模型

> 管辖规则 A-0。证据源:定稿版 §5-§11、D1/D2/D6/D7、宿主 `interp.rs`(值模型)、C 后端 `value_semantics/valueal_lite`。

### A-0 [管辖] 三层内存模型总原则
- **定义**:用户语义层只面对拥有值(String/Vec/命名类型);编译器实现层自由选择 Owned/Borrowed/Compiler View/Copied/Materialized;高级控制层提供 &T/&mut/move。("语义拥有优先,编译器借用优化,显式借用高级化",§5 冻结)
- **行为**:层间不可渗透——实现层选择永不改变用户层可观察语义(由 M-6 背书)。
- **不变量**:用户代码不书写实现层概念(除经高级层);实现层概念不泄漏进诊断(D7 口径)。
- **成熟度**:**已定义**(原则冻结);实现层仅值语义部分存在。
- 证据:§5;`interp.rs` Value 模型;C `value_semantics`。

### A-1 [定义] String 拥有语义
- 定义:`String` 永远表示拥有的字符串;字面量 `"..."`/f-string 均为 String。
- 结果:函数返回 String = 调用方获得独立拥有的值;编译器可消除分配但不可改拥有语义。
- 边界:空串、超长串同规则;无 `str` 拥有形态(str 退位,§6.2)。
- 成熟度:**已闭合(双实现一致)**;差分验证:conformance 值域用例 + 本会话字符串链修复(D15/`\x7f`)。
- 证据:§6.1;T1.0 §1.1;D15。

### A-2 [定义] `str` 退位与 `str_view` 隐藏
- 定义:`str` 不再是默认拥有类型;`&str` 为高级借用;`str_view` 为编译器内部类型,**用户源码/文档/IDE/诊断一律不得出现**(D7)。
- 失败:用户源码书写 `str_view` → 编译错误并提示改用 String/&str。
- 成熟度:**已闭合**(按 D7 口径 = "有意不支持");实现层无 str_view 类型,平凡满足。
- 证据:§6.2;D7;T1.0 §1.2。
- 税额:零(用户不可见)。

### A-3 [操作] 赋值与传参 = 值复制
- 定义:赋值/实参传递产生值的独立副本(Aine 无别名可见性)。
- 行为:宿主 = `Value` 深值复制(Vec 为 Arc 共享 + 写时深克隆,观察等效独立);C 后端 = 位拷贝 + 容器变更操作 clone-then-mutate。
- 不变量:**push/insert 等变更操作后,所有旧持有者观察不变**(C 侧由 `al_vec_clone` 前缀强制,55d6d8d 之前批次)。
- 失败/边界:无失败路径;自引用赋值 `var x = x` 由临时捕获保证读外层(55d6d8d)。
- 成熟度:**已闭合 → 待全量差分**(推:conformance 值域全量跑双路)。
- 证据:`interp.rs` eval Assign;`alee.aine` push 发射;`value_semantics`。

### A-4 [操作] 容器变更 = clone-then-mutate
- 定义:`push/insert/set` 等对共享底层缓冲的操作,先克隆再原地改。
- 交互:与 A-3 联合保证值语义;与性能税交互(每次变更 O(n) 克隆——**已知性能税,未登记**)。
- 成熟度:**已闭合(双实现一致)**。
- 证据:`alee.aine` push 发射注释;`interp.rs` Vec 方法。

### A-5 [定义] Compiler View
- 定义:编译器内部产生的临时、零成本、受验证的借用视图;不拥有、不逃逸、无 GC/RC、无生命周期参数、不改安全语义。
- 前置(D1 四条件,全部满足):函数体对参数只读;参数未逃逸;实参可追踪为本地/字段投影;非泛型(第一版硬限制)。
- 结果:lowering 后按视图实现,用户源码不可见;失败自然落入 A-6。
- 成熟度:**只有意图**(双实现零代码;D1 验收"100MB String Allocation Count == 0"未执行)。
- 证据:§7;D1。

### A-6 [操作] Materialization 回退与三档成本
- 定义:视图无法安全证明时回退物化为拥有值;Cheap(<64KB 静默)/Material(64KB-1MB 非阻塞提示)/Large(>1MB 强制提示 + 仪表盘)。
- 不变量:物化是合法安全回退;高成本物化不得静默(D2 阈值定稿数值)。
- 成熟度:**只有意图**。
- 证据:§9;D2。

### A-7 [例外] 禁止隐式大型 Clone
- 定义:编译器不得产生隐式大型数据完整复制(§10)。
- 边界:与 A-3 值复制的关系需要闭合——**push 的 O(n) 克隆(A-4)是否算"隐式大型 Clone"?Large 档 Vec.push 单次克隆是否要诊断?** ← 未定义,阶段三冲突检查对象。
- 成熟度:**只有意图**。
- 证据:§10。

### A-8 [不变量] 优化失败不是语义错误(= 元规则 M-6 的域内表述)
- 定义:任何精度组合/优化失败/缓存缺失下,同一源码产生行为一致的合法程序;差异仅允许在分配数/复制次数/代码大小。
- 成熟度:已定义(架构约束);**当前实现平凡满足**(无优化层);future VIR/Summary 落地时由差分测试背书(D6 验收:Level 0/3/5 × 缓存失效模式行为一致)。
- 证据:D6;§8.3。

### A-9 [操作] 多来源返回
- 定义:多分支返回不同来源的值,用户无需知道来源生命周期(§24);编译器能借用则优化,否则物化,成本过高建议高级 API。
- 成熟度:**只有意图**(宿主/C 均直接值返回,无来源分析;D2 View-eligible 规则未实现)。
- 证据:§24;D2。

### A-10 [定义] 所有权状态机与六个内部术语
- 定义:编译器内部维护 Ownership/Borrow/Escape/Region/Drop/Capture;对象状态流:未初始化→已初始化→持有→借出→借用结束→转移或销毁(§23)。
- **失败(审计发现 W2)**:六个术语**全部无定义**(违反 lāghava"凡可定义者当且仅当被定义");状态机无非法转换表;重复销毁/悬垂引用检查不存在(值语义下天然安全,但状态机作为 Compiler View 的前置理论应闭合)。
- 成熟度:已定义(名词存在)/**定义缺失**。
- 证据:§23;Compiler Internals。

### A-11 [元规则] 值语义下的"失效"语义缺口
- 定义:值语义 + 快照捕获 + clone-then-mutate 意味着**几乎不存在"使用已失效值"的运行时错误**——这是 Aine 安全故事的核心红利。
- 边界(未闭合):`move` 参数之后的原绑定(见 C-3)、`@global` 并发写、extern 边界。三处是值语义安全故事的例外清单,**应显式枚举并逐个闭合**。
- 成熟度:已定义(故事)/**例外清单未枚举**。
- 证据:§3.2;本表 C-3/F 域。

## C. 函数、参数与闭包

> 管辖规则 C-1。证据源:§22-§25、D5/D14、`parser.rs`/`typeck.rs`/`interp.rs`、`alparse/alee`。

### C-1 [管辖] 函数参数三模式
- 定义:普通按值(编译器可内部优化)/`move` 显式转移/`&T`·`&mut T` 高级精确(§22)。
- 成熟度:已定义;三模式实现深度差异极大(见 C-2/C-3/C-4)。
- 证据:§22。

### C-2 [操作] 普通按值参数
- 定义:按值传入,函数体内为独立副本;编译器可按 D1 条件视图化(免复制)。
- 行为:宿主 = 值复制(A-3);C = 位拷贝。
- 成熟度:**已闭合(语义)/视图化只有意图**。
- 证据:§22.1;D1。

### C-3 [定义] `move` 参数
- 定义:`move` 表示显式所有权转移;转移后原绑定应失效(§22.2"明确要求所有权转移")。
- 行为:**宿主仅解析**(`Param.is_move`,parser.rs:595)——typeck 零消费、interp 零消费、C 后端 Param 无此字段。失效规则未实现;调用方 move 后继续使用原绑定不报错。
- 失败:应当"move 后使用 = 编译错误"→ 未实现。
- 成熟度:**已定义 / 实现 = 纯语法标记(语义未执行)**。
- 证据:§22.2;parser.rs:595-610。
- **域内发现 W3**:或修语义(补失效检查),或登记"move 第一版为文档性标注"(显式决定),二选一——当前是第三种状态:语法存在但语义未决定,违反"有意识决定"纪律。

### C-4 [定义] `&T` / `&mut T` 五条规则(D5)
- 定义:①按值→`&T` 隐式 reborrow 允许;②按值→`&mut` 禁止;③一切函数禁返回 `&T`(1.0 不开放例外);④`&T` 不得存储(Vec<&T> 禁);⑤临时视图生命周期=本次调用。
- 行为:宿主 typeck 有 `Ty::Ref` 与解引用规则;**五条的编译检查实现状态逐条待验证(倾向大部分未实现)**;C 后端无引用类型系统("&" 仅为运行时取址用途)。
- 成熟度:**已定义(🟢 冻结)/实现待逐条验证**。
- 证据:D5;T1.0 §1.2;typeck.rs:98/340/636。
- **域内发现 W4**:D5.3(禁返回 &T)是可机械验证的负例,应进 conformance。

### C-5 [定义] 生命周期隐藏
- 定义:用户语法无 `'a` 参数;编译器内部完整维护(同 A-10,术语未定义)。
- 不变量:任何借用/视图的生命周期由编译器推导,用户零标注。
- 成熟度:**已闭合(语法层)**;内部理论同 A-10 缺定义。
- 证据:§23。

### C-6 [定义] 统一函数类型
- 定义:`fn(A,B)->R` 一个类型覆盖具名函数/非捕获闭包/捕获闭包;无 trait 三分法(D14.1);签名"宽松匹配"。
- 失败(未闭合):**"宽松"的精确边界未定义**——参数个数是否必须精确?返回类型协变?默认参数?← T1.0 未覆盖,D14 只说"宽松"。
- 成熟度:已定义(存在)/**匹配规则歧义待闭合**。
- 证据:D14.1;typeck `Ty::Fn`。
- **域内发现 W5**。

### C-7 [操作] 捕获即快照
- 定义:闭包创建时对捕获变量取值快照;闭包复制 = 快照独立复制;修改捕获只影响本实例(需 mut 绑定)(D14.2/3)。
- 行为:宿主 = env.snapshot() 真实实现;C 后端 = 非捕获闭包发射为函数指针,**捕获闭包的一等传递为登记在案的已知限制**(D14.4,源层等价写法 = 显式参数传入)。
- 不变量:无共享可变状态 → FnMut 类问题不存在。
- 成熟度:**已定义(宿主已闭合;C 侧已知限制已登记)**。
- 证据:§25;D14;conformance conf_closures。
- 税额:捕获闭包跨函数传递需手写参数化(已登记的 C 侧税)。

### C-8 [边界] 捕获推导优先级
- 定义:Borrow→Copy→Move 固定优先级,受逃逸/长期保存/进任务/进 UI Operation 约束(§25)。
- 边界:与 A-5 视图化条件交叉;**双实现均未实现推导**(宿主全快照,C 全指针/复制)——"已定义/实现占位"。快照策略实际使该优先级在宿主不可观察。
- 证据:§25。

### C-9 [交互] 函数 × defer
- 定义:defer 作用域 = 函数;所有退出路径 LIFO(D13)。
- 行为:宿主 = run_defers 真实实现(含 try/catch 内 `.ok()` 路径);**C 后端 = 自举 AST 无 Defer 节点(19 个 Stmt 变体无 SDefer)→ defer 程序无法走 C 路径**。
- 成熟度:已定义(🟢 D13)/宿主已闭合/C **语法未实现**(比发射缺失更早一层)。
- 证据:§27;D13;interp.rs:476-589/814-823;alparse Stmt 枚举。
- **域内发现 W6**:C 路径缺失清单更新——defer 语句 + try/catch 语句均在自举 AST 层缺失(非仅发射层)。

### C-10 [交互] 函数 × `?`
- 定义:`?` 在函数内传播 Err(§46)。
- 行为:宿主 = RtError::Propagate;C = `_r_` 检查 + 早退(Err 载荷已修)。
- 成熟度:已闭合(双实现)→ 差分验证;**非组合性热点登记**(语义孤岛:`?` 在五层各自特判,研究模块 §5.4)。
- 证据:§46;interp.rs:1205;alee ETry 臂。
